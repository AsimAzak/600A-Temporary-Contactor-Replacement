# Temporary 600 A Contactor Replacement

Temporary installation procedure for replacing a faulty 600 A contactor when the direct-fit replacement is unavailable.

> **Important:** This procedure is intended as a temporary solution only. Replace the temporary contactor with the correct direct-fit component as soon as it becomes available.

## Overview

The temporary 600 A contactor is not a direct-fit replacement for the original contactor. This procedure provides the required installation and wiring modifications to temporarily return the battery to service.

## Procedure

### 1. Record Existing Polarity

Before removing the faulty contactor, identify and document the polarity of the **12 V control wiring**.

### 2. Remove the Faulty Contactor

1. Remove the busbars from the faulty contactor.
2. Remove the faulty contactor from the battery.
3. Retain the hardware as required for the temporary installation.

### 3. Install the Busbars

Attach the existing busbars to the temporary 600 A contactor.

* Leave the busbar bolts loose initially.
* Do not fully torque the connections until alignment is complete.

### 4. Mount the Temporary Contactor

Position the temporary contactor inside the battery.

Secure the contactor using **only the two screws on the left side of the base plate**.

### 5. Align and Torque the Busbars

Adjust the busbars as necessary to align them with the existing circuit connections.

Once properly aligned:

**Torque: 13 N·m**

Verify that the busbars are properly seated and that there is no excessive mechanical stress on the contactor terminals.

### 6. Connect the 12 V Control Wiring

The temporary contactor uses the **opposite 12 V control polarity** compared with the original contactor.

Connect the control wires according to the polarity required by the temporary contactor.

**Verify polarity before applying power.**

## Final Inspection

Before returning the battery to service:

* [ ] Verify busbar alignment.
* [ ] Verify all busbar connections are torqued to **13 N·m**.
* [ ] Verify contactor mounting.
* [ ] Verify 12 V control-wire polarity.
* [ ] Confirm there are no loose components or unintended contact points.
* [ ] Perform the appropriate functional test before returning the battery to operation.

## Disclaimer

This procedure is intended for qualified technicians familiar with high-current battery systems. Follow all applicable electrical safety procedures and manufacturer requirements. The temporary installation should only be used until the correct direct-fit replacement is available.
